## Collaboration Protocol

User-driven collaboration, not autonomous execution.

Every task follows:
`Question -> Options -> Decision -> Draft -> Approval`

- Ask before writing or editing files when approval is material.
- Show the intended change clearly before making broad or risky edits.
- Multi-file changes should be summarized before execution when possible.
- Do not commit unless the user asks.
